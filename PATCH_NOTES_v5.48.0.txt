wx-pnxbj 后端 v5.48.0

新增：
1. 运行配置 debugEntryCode，默认9999，仅管理后台可读取/修改。
2. POST /api/debug/verify，用于小游戏启动参数 ts 的四位调试口令校验。
3. 公共 GET /api/config 会移除 debugEntryCode，避免把口令明文下发客户端。
4. 调试校验按来源地址做简单频率限制。
5. 玩家资料更新保护：空头像与“微信用户/微信玩家”等占位昵称不覆盖已有真实资料。
6. 管理后台运行配置新增“四位URL强制调试口令”输入框。

部署：覆盖现有 wx-pnxbj GitHub 仓库根目录即可，不需要新增环境变量，不需要重新挂载 /data。
